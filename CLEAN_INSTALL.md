CLEAN INSTALL

1. Create ONE GitHub repository named NFL-Picker-V3.
2. Upload the CONTENTS of this folder directly to the repository root.
3. The repository main page must show app.py, requirements.txt, config.json, src, data, and .streamlit.
4. Inside src/nfl_picker_v3 you must see __init__.py, data.py, features.py, model.py, engine.py, backtest_engine.py, and training.py.
5. In Streamlit create ONE app using repository NFL-Picker-V3, branch main, main file path app.py.
6. Do not use a nested app path.
7. Expected tabs: Weekly Picks, Week Backtest, Season Backtest, ML Training.
